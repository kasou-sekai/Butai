# Butai

**让每个桌面，各就各位。**

Butai 是一款 macOS 桌面工作区助手。它保留你熟悉的触控板手势、Mission Control 和系统快捷键，同时为不同桌面添加名称、快速切换和窗口预设。

你可以把“开发”“设计”“会议”或“休闲”分别放在不同桌面，并让 Butai 帮你记住每个桌面需要的应用、文件夹、网页和窗口位置。

## 主要功能

- 为不同桌面设置容易辨认的名称；
- 在屏幕顶部显示当前桌面名称；
- 从顶部浮窗或菜单栏快速切换桌面；
- 识别普通桌面和全屏应用所在的空间；
- 从当前窗口快速保存工作区预设；
- 补全尚未打开的应用、文件、文件夹和网页；
- 恢复已保存窗口的位置与大小；
- 为不同显示器分别保存工作区名称和预设；
- 支持 Finder、Visual Studio Code、VSCodium、Microsoft Edge 和 ChatGPT / Codex；
- 逐项显示预设执行结果，方便了解哪些内容已完成或需要处理。

Butai 不会为了恢复预设而关闭额外窗口、退出应用或丢弃未保存的内容。

## 开始使用

1. 将 `Butai.app` 放入“应用程序”文件夹并打开。
2. 按提示授予辅助功能和桌面导航所需权限。
3. 在 Mission Control 中准备好你需要的桌面。
4. 打开 Butai 设置，为各个桌面命名。
5. 切换到一个桌面，在“预设”中选择“从当前窗口创建”。

完成后，你可以从屏幕顶部浮窗或菜单栏进入任意工作区。

## 预设

每个工作区可以保存一组需要的内容，例如：

- 一个应用；
- 文件或 Finder 文件夹；
- 网页；
- VS Code 文件夹或工作区；
- 包含多个网页的 Edge 窗口；
- ChatGPT / Codex 应用窗口。

“补全”只打开当前缺少的内容；“恢复布局”还会将能够可靠识别的窗口恢复到保存的位置和大小。

## 顶部浮窗

顶部浮窗会显示当前工作区名称。将鼠标移到浮窗上，可以查看所有桌面和全屏应用并快速切换。

你可以在设置中：

- 隐藏浮窗；
- 调整顶部偏移；
- 自定义宽度和高度；
- 选择在全屏应用中隐藏、靠近顶部时显示或始终显示。

## 系统要求

- macOS 14 Sonoma 或更高版本；
- 建议关闭“根据最近的使用情况自动重新排列 Spaces”；
- 窗口识别和布局恢复需要辅助功能权限；
- 桌面切换需要允许 Butai 发送导航事件。

## 当前限制

- 最多管理 9 个普通桌面；
- Split View 和 Stage Manager 暂不支持；
- 多显示器会分别保存设置，但不支持同时控制多台显示器上的桌面切换；
- ChatGPT / Codex 可以启动、激活和恢复窗口布局，但不能保证打开指定对话或创建额外窗口；
- 通用应用通常会复用或激活已有窗口，不能保证创建新窗口；
- Caps Lock 快捷键、登录时启动和自动更新暂未提供。

## 隐私

Butai 的工作区名称、文件路径、网页地址和窗口信息保存在本机，不会上传。辅助功能权限仅用于识别窗口、切换桌面以及执行你主动触发的预设操作。

## 安全原则

Butai 以保护当前工作为优先：

- 不自动关闭窗口；
- 不自动退出应用；
- 不执行命令行预设；
- 不移动无法可靠识别的窗口；
- 配置异常时不会用空配置覆盖原文件。
